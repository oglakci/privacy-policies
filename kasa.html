Toplanan Veriler

  • Ad ve e-posta adresi (kayıt için)
  • Belge görselleri (fiş, fatura, garanti belgesi)
  • Ürün bilgileri (ad, marka, fiyat, tarih)
  • Garanti ve iade tarihleri
  • Bildirim tercihleri

Verilerin Saklanması

Belgeleriniz ve ürün bilgileriniz Supabase altyapısında güvenli biçimde saklanır. Verileriniz yalnızca size aittir ve üçüncü taraflarla paylaşılmaz.

Yapay Zeka İşleme

Yüklediğiniz belge görselleri, içerik çıkarma amacıyla Google Cloud Vision (OCR) ve Anthropic Claude API üzerinden işlenir. Bu işlem yalnızca belge bilgilerini otomatik doldurmak için kullanılır.

Üçüncü Taraf Hizmetler

  • Supabase — veritabanı ve kimlik doğrulama
  • Google Cloud Vision — belge OCR işleme
  • Anthropic Claude API — içerik analizi

KVKK Haklarınız

  • Verilerinize erişme hakkı
  • Verilerinizi silme hakkı (hesabı silerek tüm veriler kalıcı olarak silinir)
  • Verilerinizi düzeltme hakkı
  • Veri taşıma hakkı

Veri Güvenliği

Verileriniz endüstri standardı şifreleme yöntemleriyle korunmaktadır. Supabase'in güvenlik politikasına buradan ulaşabilirsiniz.
